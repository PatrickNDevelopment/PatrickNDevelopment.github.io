# AI assistance

This site and the projects it presents were implemented with Anthropic's Claude (through Claude
Code) as the implementing engineer, under the owner's direction and review; the written
specifications were also produced with Claude Code. Each project was then checked by a separate
Claude Code session that did not write its code. Those acceptance reviews are AI reviews, not human
code or security audits. The site says this on every case study and in its "Responsible AI" section.

The site's content was compiled from the projects' own documentation and test reports; treat
`docs/test-report.md` here and in each project, not this note, as the evidence of what works.
