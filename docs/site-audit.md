  band edge is faint but nothing depends on it.

  catch number, status, commit and URL drift, not wording drift.
- Not done: Firefox, Safari, screen-reader and 200 % zoom sessions; CI and Pages have never run.

  which ends every Node.js process on the machine, not only the server it started. No other work was
  known to be running; future sessions should stop servers by process id.
