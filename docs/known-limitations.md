# Known limitations

- **Not published.** No remote, CI and the Pages workflow have not run. Canonical and Open Graph
  URLs name the user-site address, which is not live yet.

- **Content is maintained by hand** from each project's documents; the local registry check catches
  status, commit and demo-URL drift but not wording drift in the longer descriptions.
- **No personal details** beyond the GitHub handle: no name, e-mail, LinkedIn or résumé until the
  owner approves specific public details.
- **Screenshots are PNG** copies from the projects (about 3.4 MB in total, lazily loaded); no WebP or
  responsive image sets yet.
- **Open Graph images** reuse project screenshots rather than purpose-made 1200 × 630 images.
- Tested in Microsoft Edge (Chromium) on Windows; no Firefox, Safari or screen-reader session.
- **Acceptance reviews are AI sessions.** The 11B audit, like each project's review, was done by a
  separate Claude Code session; there has been no human code, security or accessibility audit.
- In dark mode the navy header band is close to the page background, so its edge is faint.
